# Mosaico — atualizações

Atualizações da tela inicial Mosaico para TV box Android.

- `versao.json`: a versão publicada, o endereço do APK e o SHA-256 dele.
- `mosaico-<versão>.apk`: o instalador.

A TV confere este arquivo sozinha a cada 12 horas e mostra "Nova versão: atualizar" na tela inicial.
Antes de instalar, o Mosaico confere o SHA-256. O Android só aceita a atualização se ela tiver a mesma assinatura da versão instalada.

O código-fonte fica em um repositório privado.
